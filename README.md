## Project spotlight: NeuroSeg

[![NeuroSeg MRI research dashboard](https://raw.githubusercontent.com/Izharullah733/neuroseg-brain-tumor-segmentation/main/docs/screenshots/dashboard.png)](https://github.com/Izharullah733/neuroseg-brain-tumor-segmentation)

NeuroSeg combines a compact segmentation model with MRI visualization, native-grid
mask export, and downloadable PDF/CSV reports. The current work is a small-cohort
research pilot, not a clinically validated diagnostic system.

[Explore the code](https://github.com/Izharullah733/neuroseg-brain-tumor-segmentation)

· [See the limitations](https://github.com/Izharullah733/neuroseg-brain-tumor-segmentation/blob/main/docs/MODEL_CARD.md)
